# LBC-003 · Contract-based C2 address resolution

Evidence: **Observed** · Reviewed 2026-10-16
Chains: Ethereum, BNB Smart Chain, Polygon · Networks: Mainnet, Testnet

A stable contract supplies the current off-chain C2 location.

## Analysis procedure

### Collect

Contract getter request, relevant caller fields, resolver output and configured provider set.

### Inspect

Decode the returned pointer and compare block-pinned answers; reproduce any evidenced decryption or provider-voting rule.

### Correlate

Find the downstream connection in endpoint telemetry and distinguish it from the RPC request.

### Interpretation limits

A public provider is not the C2. A configured provider list is not proof that every provider was contacted.

Methods: [EVM contracts and transaction data](evm.md).

## Catalog context

Contract getters supply an off-chain destination. Sysdig documents nine-provider majority voting; Hunt.io lists seven configured providers and periodic refresh; RedLine-lineage samples decrypt BSC resolver data. REVSTEALER uses an encrypted Polygon fallback. PasteSwitch mirrors BSC testnet/mainnet updates and disguises a getter as balanceOf. HexMage uses Sepolia pointers. A provider, contract, downstream C2 and exfiltration server are distinct objects. Chainalysis separately identifies Polygon resolvers and BSC resolver fleets administered by shared operators.

Examples: EtherRAT; Tsundere; RedLine-lineage resolver; REVSTEALER; AnimateClipper / Zig; HexMage

### Detection guidance

Correlate RPC fan-out or repeated getters with newly contacted destinations. Retain chain ID, selector, address, process and request timing. Familiar ERC-20 selectors such as balanceOf do not prove a benign token lookup.

### Defensive approach

Baseline RPC use by host and process. Deny unsanctioned providers and investigate the returned destination.

## ATT&CK assessment

Enterprise · Technique · Reported behavior

The contract supplies a pointer to a separate C2 service. This mapping concerns address resolution, not every request to an Ethereum RPC provider.
