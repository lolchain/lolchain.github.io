### Correlate

## Catalog context

Sucuri describes cooperating WordPress persistence locations. The payload uses public Ethereum RPC gateways and smart-contract selectors as a control channel; response details and the network ID are not published. It encrypts site information and administrator-session material and POSTs it to an off-chain resolved endpoint. The report publishes no complete contract address or exact gateway hosts.

Examples: SC WordPress backdoor

### Detection guidance

Review PHP egress, WordPress drop-ins, plugins, database persistence and unexpected administrator-session access. Join RPC reads to subsequent outbound POSTs.

### Defensive approach

Remove all cooperating persistence locations and rotate exposed sessions and secrets. Rebuilding only one plugin may leave the mesh intact.
