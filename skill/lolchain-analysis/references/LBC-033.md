# LBC-033 · Blockchain-staged browser WebRTC payload channel

Evidence: **Observed** · Reviewed 2026-10-15
Chains: BNB Smart Chain · Networks: Testnet

An on-chain browser loader receives its next code stage through a WebRTC data channel.

## Analysis procedure

### Collect

BSC-testnet getter response, staged JavaScript, SDP/ICE/DTLS parameters and browser session evidence.

### Inspect

Decode the returned script offline; preserve hardcoded signaling material and any CSP nonce/Function branch.

### Correlate

Match ICE negotiation and a selected WebRTC data channel to buffered payload bytes and later DOM/execution artifacts.

### Interpretation limits

SDP in chain data is signaling, not the payload transport itself. A failed negotiation does not prove delivery or on-chain exfiltration.

Methods: [EVM contracts and transaction data](evm.md).

## Catalog context

BSC-testnet eth_call returns JavaScript with a hardcoded SDP answer and ICE/DTLS parameters. This avoids a separate external signaling exchange, then opens a UDP WebRTC data channel and buffers attacker code. DOM injection reuses a page CSP nonce, with a Function fallback. The payload channel is off-chain; no on-chain exfiltration is established.

Examples: BSC-testnet stager analyzed by Netskope

### Detection guidance

Join browser contract reads to unexpected UDP/WebRTC destinations and subsequent script execution. HTTP-only gateway logs may miss the data channel; preserve browser and endpoint telemetry.

### Defensive approach

Remove injected web loaders and investigate downloaded stages. Review WebRTC egress policy and confirmed remote resources; RPC blocking alone does not cover an already loaded UDP stage.

## ATT&CK assessment

Enterprise · Technique · Reported behavior

Retrieving code through the staged browser/WebRTC path supports Ingress Tool Transfer. The off-chain WebRTC transport and CSP-nonce reuse do not alone establish a precise C2 or exfiltration sub-technique. No data removal through the chain is asserted.

- [TA0011 · Command and Control](https://attack.mitre.org/tactics/TA0011/)
- [T1105 · Ingress Tool Transfer](https://attack.mitre.org/techniques/T1105/)
