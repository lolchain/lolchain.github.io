### Detection guidance

Look for unexpected TON API getter requests followed by new WebSocket connections. Preserve route, method and returned domain where available.

### Defensive approach

Baseline TON API use; block validated downstream resources and remove the implant. Do not infer a full contract address from the redacted source.
