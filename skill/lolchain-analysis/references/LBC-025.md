### Inspect

### Correlate

## Catalog context

The mFT conference research presents NFT-based command relay and information-return possibilities. This entry documents the demonstration, not an operational malware campaign.

Examples: mFT / DEF CON 32 demonstration

### Detection guidance

Inspect unusual token or metadata retrieval alongside execution and local data collection. NFTs alone do not execute code on an endpoint.

### Defensive approach

Apply process-aware egress policy and inspect the consuming application; use a specific token or contract only with corroborating evidence.
