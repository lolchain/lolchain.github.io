# LBC-010 · Blockchain DNS for C2 and delivery

Evidence: **Observed** · Reviewed 2026-10-15
Chains: Namecoin · Networks: Mainnet

Blockchain-backed names provide an alternative to conventional DNS registration.

## Analysis procedure

### Collect

Original .bit name, resolver configuration, chain record and observed DNS/HTTP resolution path.

### Inspect

Capture the available record/history and expiration context; separate Namecoin data from gateway/resolver responses.

### Correlate

Compare the incident-time answer with the actual download/C2 destination from the host.

### Interpretation limits

Current records can differ from historical answers. Ordinary gateway DNS infrastructure is not the blockchain name itself.

Methods: [Canisters, naming and NFTs](services.md).

## Catalog context

Microsoft and Mandiant document .bit resolution in malware, including use of alternative resolvers to find C2 or download infrastructure.

Examples: RTM; Dofoil / Smoke Loader; Terdot; GandCrab

### Detection guidance

Inspect .bit lookups, custom Namecoin API reads and DNS sent to external resolvers. Correlate name-operation changes with resolved connections. A wallet funding a name is context, not an automatic maliciousness verdict.

### Defensive approach

Enforce approved DNS paths and inspect resolved connections. Treat historical .bit indicators as investigation leads.

## ATT&CK assessment

Enterprise · Tactic only · Reported behavior

Blockchain names support C2 discovery, but the entry does not establish DGA, fast flux, DNS calculations or commands tunneled in DNS. No specific technique is forced from the .bit suffix.

- [TA0011 · Command and Control](https://attack.mitre.org/tactics/TA0011/)
