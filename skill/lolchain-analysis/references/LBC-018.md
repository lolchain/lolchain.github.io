## Analysis procedure

### Collect

Canister principal/hostname, polling request, returned URL and loader artifact.

### Inspect

Inspect the exact canister response and method; preserve query/update/HTTP distinctions and certification context.

### Correlate

Find the subsequent fetch in host telemetry and preserve the downloaded artifact hash.

### Interpretation limits

A shared parent domain is broader than the canister hostname. Query readers are not enumerable as ordinary ledger transactions.

Methods: [Canisters, naming and NFTs](services.md).

## Catalog context

Aikido documents a Python backdoor polling a specific ICP canister for a download URL. The full canister hostname is a more precise control than the shared parent domain.

Examples: TeamPCP / CanisterWorm

### Detection guidance

Hunt periodic requests to canister hosts from interpreters and developer or CI endpoints.

### Defensive approach

Block confirmed canister resources, investigate compromised packages, and rotate affected developer credentials.

## ATT&CK assessment

Enterprise · Technique · Reported behavior

The canister supplies a separate payload URL; the implant then downloads the payload. MITRE also lists CanisterWorm under Dead Drop Resolver, but this catalog mapping remains an analyst assessment.
