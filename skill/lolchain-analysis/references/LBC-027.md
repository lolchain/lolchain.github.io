# LBC-027 · Blockchain-backed ClickFix execution

Evidence: **Observed** · Reviewed 2026-10-16
Chains: BNB Smart Chain, Base, Polygon · Networks: Mainnet, Testnet

Contract-supplied scripts lead a user into copying and running a command.

## Analysis procedure

### Collect

Page/loader, chain-returned lure code, displayed instruction and browser-to-shell evidence.

### Inspect

Decode the chain stage as inert text and separate it from the user instruction and shell command.

### Correlate

Correlate copy/paste or execution artifacts with the subsequent payload; record gaps if only the lure was seen.

### Interpretation limits

A blockchain request alone does not prove ClickFix execution. General ClickFix detections are not blockchain-specific evidence.

Methods: [EVM contracts and transaction data](evm.md).

## Catalog context

The chain stages or resolves the lure code; the social-engineering step prompts manual execution. This is distinct from the blockchain call itself. Sources document testnet contract stages and browser-to-shell delivery.

Examples: ClearFake fake-CAPTCHA and update lures

### Detection guidance

Join suspicious RPC or injected web script activity to clipboard-related lures and browser-followed shell execution. Preserve the lure and script evidence.

### Defensive approach

Use script controls and endpoint execution policies; investigate the initial compromised site and the command execution chain.

## ATT&CK assessment

Enterprise · Technique · Reported behavior

The reported ClickFix lure asks a user to copy and execute a command. This maps the manual execution behavior; a contract read or fake CAPTCHA alone is insufficient.

- [TA0002 · Execution](https://attack.mitre.org/tactics/TA0002/)
- [T1204.004 · User Execution: Malicious Copy and Paste](https://attack.mitre.org/techniques/T1204/004/)
