# LBC-029 · Split-secret encrypted contract configuration

Evidence: **Observed** · Reviewed 2026-10-16
Chains: Ethereum · Networks: Testnet

Recovering a destination requires both on-chain ciphertext and site-held secret material.

## Analysis procedure

### Collect

Encrypted contract value, compromised-site password/key material and the decoding routine.

### Inspect

Preserve both halves and provenance; reproduce decryption offline with input/output hashes.

### Correlate

Link the recovered destination only to the individually evidenced encrypted loader and its network behavior.

### Interpretation limits

A contract alone may be insufficient. Do not attach the whole plaintext tracker or infer encrypted transport from encrypted storage.

Methods: [EVM contracts and transaction data](evm.md).

## Catalog context

Source Defense reports contract values carrying encrypted configuration while a compromised website supplies separate password material. The public chain object alone does not disclose the destination. This is storage encryption, not evidence that every C2 transport is encrypted. Confiant independently identifies encrypted variants and their loader-held secrets. Only individually evidenced encrypted destinations are linked to this record; the wider tracker includes plaintext cases.

Examples: Encrypted Sepolia Magecart configuration

### Detection guidance

Preserve the injected web loader with the contract response. Link decryption activity to the resolved destination; a contract-only extraction may be incomplete.

### Defensive approach

Remove site injection and investigate the resulting destination. Keep secrets from incident evidence private; use contract and source context for network controls.

## ATT&CK assessment

Enterprise · Technique · Reported behavior

After combining site-held material and contract configuration, the loader recovers an off-chain destination. Encrypted configuration storage alone does not establish Encrypted Channel or encrypted transport.

- [TA0011 · Command and Control](https://attack.mitre.org/tactics/TA0011/)
- [T1102.001 · Web Service: Dead Drop Resolver](https://attack.mitre.org/techniques/T1102/001/)
